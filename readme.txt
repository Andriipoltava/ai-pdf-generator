Generate professional PDF documents, invoices, and certificates instantly using your own OpenAI or Google Gemini API key.

== Description ==

**AI PDF Generator** is a lightweight, powerful plugin that brings the power of AI right into your WordPress dashboard to generate beautiful PDF documents.

Whether you need a quick invoice for a client, a certificate of completion, or a custom summary report, this plugin lets you create it in seconds. You can use your own **OpenAI (ChatGPT)** or **Google Gemini** API key to generate custom text and structures based on your prompts.

Don't have an API key yet? No problem! The plugin comes with **built-in static templates** (like Invoices and Certificates) that work perfectly out of the box without any third-party services.

### Key Features
* **Bring Your Own Key (BYOK):** Use your own OpenAI or Gemini API key. No hidden subscriptions or locked features.
* **Static Templates:** Generate Invoices and Certificates instantly without any API connections.
* **Custom Branding:** Apply your own logo, brand colors, and company details to all generated PDFs.
* **Download instantly:** Generates high-quality PDFs on the fly.
* **Clean & Lightweight:** No external services required for the core PDF features.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory, or install it directly through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Navigate to **AI PDF Generator -> Settings** to enter your OpenAI or Gemini API key (optional).
4. Go to the **Branding** tab to set up your logo and company details.
5. Open the **PDF Generator** tab to start creating documents!

== Frequently Asked Questions ==

= Is this plugin really free? =
Yes, the plugin itself is 100% free. You only pay for the API usage directly to OpenAI or Google if you choose to use the AI-generation features. The static templates are completely free to use.

= Where is the data processed? =
If you use the static templates, everything is processed locally on your server. If you use the AI generation, your prompt is sent directly to the official OpenAI or Google API. No data is sent to our servers.

= Does this plugin require an API key? =
No. The built-in static templates (Invoice and Certificate) work immediately after activation. An API key is only needed if you want to generate custom documents from a text prompt using OpenAI or Gemini.
